# Flutter App con Supabase

Aplicación de Flutter para gestionar tareas con autenticación de usuarios y almacenamiento en Supabase.

## Descripción

Esta app permite:

- Registro e inicio de sesión con Supabase Auth
- Crear nuevas tareas
- Marcar tareas como completadas
- Eliminar tareas
- Cargar la lista de tareas desde una base de datos PostgreSQL en Supabase

La interfaz está construida con Flutter y Material Design, y usa el paquete `supabase_flutter` para conectarse a Supabase.

## Configuración

1. Clona el repositorio:

```bash
git clone https://github.com/Jjuanfe/flutter_application_supabase_1.git
cd flutter_application_supabase_1
```

2. Instala las dependencias:

```bash
flutter pub get
```

3. Crea un proyecto en Supabase.

4. Configura las credenciales en `lib/main.dart`:

```dart
const String SUPABASE_URL = 'https://tu-proyecto.supabase.co';
const String SUPABASE_ANON_KEY = 'tu_anon_key';
```

> En una app real, es recomendable no guardar claves sensibles directamente en el código. Puedes mover estas configuraciones a variables de entorno o a un archivo de configuración seguro.

## Base de datos recomendada

El proyecto asume una tabla llamada `tareas` en Supabase. Un ejemplo de esquema es:

```sql
create table public.tareas (
  id bigint generated by default as identity primary key,
  titulo text not null,
  hecho boolean not null default false,
  created_at timestamp with time zone default now()
);
```

También puedes habilitar políticas de acceso según tu flujo de autenticación.
